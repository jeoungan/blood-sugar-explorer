# 혈당 자료 탐색

2026년 10월 23일부터 11월 6일까지 측정한 혈당 207건과 15일간의 생활 일정을 비교하는 웹사이트입니다.

**사이트:** https://jeoungan.github.io/blood-sugar-explorer/

## 기능

- 하루별 그래프, 최대 5일 겹치기, 전체 15일 보기, 겹친 하루 백분위, 두 날짜 비교
- 시간대 필터, 평균·표본 표준편차·최저·최고와 범위별 관측값 비율
- 실제 측정점과 옅은 점선 연결, 2시간 초과 간격 단절
- 같은 시간축의 스케줄 색상 띠와 표시 온오프
- 측정 시각별 활동·메모 확인 및 전체 기록 CSV 다운로드

## 공개 데이터와 사진

이 공개판에는 소유자가 공개를 승인한 혈당값·측정 메모·생활 일정이 포함됩니다. **개인 측정 사진은 저장소와 사이트에 포함하지 않습니다.** 데이터 재가져오기 스크립트도 사진을 복사하지 않으며, 배포 전에 사진 파일과 사진 참조가 없는지 검사합니다.

## 실행 및 배포

Node.js가 있는 환경에서 `npm start`로 실행하고 `http://127.0.0.1:4317`을 엽니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

`npm test`는 혈당 데이터, 스케줄의 시간 구간, 사진 제외 조건을 검증합니다. `main` 브랜치 변경 시 GitHub Actions가 검증을 거쳐 `dist/`를 GitHub Pages에 배포합니다.

## 데이터 갱신

Python의 `openpyxl`이 있는 환경에서 `python scripts/import_workbook.py <혈당 엑셀 경로>`와 `python scripts/import_schedule.py <스케줄 엑셀 경로>`로 데이터를 가져올 수 있습니다. 날짜 범위가 달라지면 제목·안내 문구와 비교 날짜 기본값도 함께 확인해야 합니다.

평균·표준편차와 비율은 실제 관측값으로만 계산합니다. 점선은 측정 사이의 추정 연결이며 새 관측값을 생성하지 않습니다. 스케줄은 기억을 바탕으로 작성한 30분 단위 참고 자료입니다.

## 참고

보고서에 사용한 관측 통계와 그래프는 `analysis/report_analysis.py`로 재현할 수 있습니다. `openpyxl`과 `matplotlib`을 설치한 환경에서 `python analysis/report_analysis.py --input <혈당 엑셀 경로> --output report-data`를 실행합니다. 원본 엑셀과 분석 결과는 공개 저장소에 포함하지 않습니다.
